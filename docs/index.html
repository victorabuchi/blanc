01 — Overview

Built for label-style stores

Beyond the standard commerce templates, Blanc ships a set of brand pages: a New page for current arrivals, Combos for curated outfits, Collabs for partner releases, and an Archive for past collections. The visual language is black-on-white with small tracked uppercase type and blue hyperlink-style product titles — everything else (cart, search, help) is built to stay out of the way of the product.

No build step. The theme is plain Liquid, CSS and JS — clone it, point the Shopify CLI at a development store, and start editing:

shopify theme dev

02 — Page setup

Assigning the brand pages

New, Combos, Collabs, Archive and Contact are Shopify Pages, not collections. The templates ship with the theme, but each page only goes live once it's created in the admin and given its template.

Page titleTemplateNotes
Newpage.newCurrent arrivals
Combospage.combosCurated outfits
Collabspage.collabsHidden from nav by default — see below
Archivepage.archivePast collections, one entry per block
Contactpage.contactStandalone contact form

To assign one

Online Store → Pages → Add page → set the title (this becomes the URL handle) → under Theme template choose the matching entry above → Save.

Collabs is hidden by default

The nav link is commented out in sections/header.liquid until the page is ready — uncomment it to bring Collabs into New / Combos / Archive / Discover.

03 — Homepage sections

Six independent sections

The homepage is assembled from six reorderable sections rather than one fixed layout — add, remove, duplicate or drag any of them from the theme editor.

  • 01
    HeroFull-bleed image, optional announcement bar, headline and link.
  • 02
    Featured collectionA horizontal scrolling carousel pulling from a merchant-picked collection.
  • 03
    Image bannerOne full-width campaign image with an overlay heading and link.
  • 04
    Two-column bannerTwo image blocks side by side — each reveals its link label on hover.
  • 05
    Category gridA block-based grid of image tiles — add as many as the collection needs.
  • 06
    NewsA text column beside a horizontal media carousel that mixes image and video blocks.

04 — Theme settings

Colors & typography

Nothing below is hardcoded — every value is a theme setting, emitted as a CSS custom property and consumed throughout assets/theme.css.

Background#ffffff
Text#1a1a1a
Accent#0000ee
Secondary background#f5f5f3
Secondary text#707070
Border#e8e8e8

Secondary text is kept dark enough to clear WCAG AA contrast (4.5:1) against the background — adjust it, but check contrast before shipping a lighter value.

Fonts

Heading and body fonts are set independently via font_picker, defaulting to Oswald (700) for headings and Assistant (400) for body copy. Both load through font_face/font_modify in layout/theme.liquid, with bold and italic variants generated automatically.

Favicon

A single image setting — 64×64px PNG recommended.

06 — FAQ

Common questions

Do I need to know how to code to use Blanc?

No. Colors, fonts, homepage sections, and every page's content are configurable from the theme editor. Code access is only needed if you want to change behavior beyond what a setting exposes.

How do I get the New, Combos, Archive and Contact pages live?

They're Shopify Pages, not automatic — see Page setup above for the exact template to assign each one.

Can I reorder or remove homepage sections?

Yes — all six are independent, editor-managed sections. Drag to reorder, or use "Add section" to bring in more of the same type (a second Featured collection, another Image banner, and so on).

Does Blanc work with multiple languages and currencies?

Yes — it uses Shopify's standard localization and markets features throughout, with no theme-side configuration required beyond what Shopify's admin already provides.

What if I find a bug or need a customization?

Bug reports and usage questions go to the support email below and get a response within 2 business days. Custom coding work beyond the theme's built-in settings isn't included, but we're happy to point you to a Shopify Partner if you need it — always duplicate the theme before editing code directly.
